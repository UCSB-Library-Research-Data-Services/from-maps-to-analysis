Working with Data

Learning Objectives

This lesson focuses on learning more about the different types of geographic data and learning how to import and work with your own data in ArcGIS Online. At the end of this workshop you will:

  • Have a better understanding of various vector and raster geospatial data types
  • Know how to import external tabular data into ArcGIS Online
  • Know how to edit or add data to a feature layer
  • Better understand the difference between continuous and categorical raster layers
  • Know how to export data from ArcGIS Online to your local machine

Review: Annotations vs. Data

In Workshop 1, we started with sketch layers to draw points, lines, and polygons directly on top of the map. While sketches are convenient for quick markups and annotations, they are not true GIS data layers. Sketches lack an underlying database table and cannot be queried, filtered, or used in spatial analysis.

In contrast, feature layers link geometries (points, lines, or polygons) to structured records in an attribute table. Each feature has defined attributes, or fields (e.g., name, speed limit, road type, elevation) with specific data types (such as text strings, numbers, and dates). This tabular structure makes it possible to filter features, symbolize data based on its attributes, and calculate spatial relationships.

Raster vs Vector Data

Geographic data generally falls into two primary models: vector and raster.

Vector Data

In workshop 1, we only briefly looked at vector data. Vector data represents discrete geographic features using coordinate geometry:

  • Points: Single \((X, Y)\) coordinate pairs representing discrete locations (e.g., bike racks, bus stops, accident locations).
  • Lines (and Polylines): Ordered sequences of vertices connecting locations to represent linear features or networks (e.g., bike paths, roads, transit routes, streams).
  • Polygons: Closed shapes enclosing an area defined by connected coordinate vertices (e.g., campus buildings, land parcels, parks, water bodies).

Every shape is tied to a row in an attribute table, where each column holds specific properties describing that feature. For example, in our Workshop 1 example, we can pop open the attribute table and look at the attributes (the row) for the “Library” building:

Visually selecting the library building polygon on the map will select its row in the attribute table.

Then opening the Attribute Table under layer options by clicking Layers > UCSB Campus Buldings 2026, the ... > Show table

Each polygon in the table has many fields and values associated with it. Building names, floor counts, area, who edited the file, and when it was last updated, among other fields a user may find helpful when analyzing their data.

Attributes of both pixels and polygons may be divided into three main types:

  • Nominal: free-text information for labels and names
  • Categorical; data that conforms to a controlled vocabulary
  • Numeric: both continuous and ordinal information that can be counted ie the number of floors that each building has (note: the UCSB Library has a basement and attic. Hence 10) or the area of each building’s floorspace.

Raster Data

Raster data represents the landscape as a regular grid of square cells (pixels) organized into rows and columns.

  • Single-band rasters: Each pixel contains a single numerical value representing a continuous measurement (such as elevation in a Digital Elevation Model [DEM], slope, or temperature) or an integer code representing a category (such as land cover types).
  • Multi-band rasters: Each pixel contains multiple values across different spectral channels or bands (such as red, green, blue, and near-infrared bands in aerial photography or satellite imagery).

Exploring Raster Data

When outside of ArcGIS Online, geospatial raster data comes in many different formats. TIFFs, Grids, netCDF, iiif, web map services. Too many to list!

  • ArcGIS Online variations: while many of these start somewhere as TIFFs, they are all ingested into AGO as flavors of Tiled imagery layers

Let’s add a Digital Elevation Model to out map: ucsb_local_dem. By default, a single channel or one band raster is displayed as grayscale, with low values black and high values white.

Your map with DEM should look something like this by default:

Each pixel, or cell, in our DEM represents bare-earth (ie: with trees and buildings removed) surface elevation relative to a vertical datum (mean sea level). The ucsb_local_dem dataset was derived from a high-resolution USGS LiDAR survey (3D Elevation Program (3DEP)). Sometimes this is called a Digital Terrain Model (DTM)

A DEM is an example of a continuous raster as the values stored in each cell correspond to a quantity gradient (elevation in meters) changing in space . Other examples of continuous raster would be precipitation measurements, air quality index, ocean salinity, or distance from a road.

In the layer properties, explore the raster statistics: note the minimum elevation near sea level (0) along the coast and slough, rising to hundreds of feet in the foothills, as well as the grid cell resolution.

TipChallenge: Does our DEM contain negative values? Why?

Yes. Because our data is both elevation and bathymetry. You can see the range of values in the properties window of a raster.

Applying a Continuous Divergent Color Scheme

Data that moves around a zero point, such as our batho-topo elevation model, is knows as ** divergent **. It is very helpful to your map viewers to visualize this typ of data with a divergent color scheme.

By default, continuous raster layers display using a grayscale “Stretch” renderer (low values ‘0’ dark, and high values 255 light). To clearly distinguish elevation changes across the coastal plain and mountains, let’s change the symbology to a continuous, diverging color ramp (e.g., a below-and-above zero diverging ramp or an elevation palette). Select the DEM layer and open the Styles menu ()

to use ‘Stretch’, we have to force zero to be the middle value. When we need to do this, we look at the DEM’s actual minimum and maximum values, and take whichever number has the larger absolute value. Use that exact number as both a negative minimum and a positive maximum in the Statistics table. (e.g.: 1218 feet)

Categorical Rasters - Land Cover

Categorical vs. Continuous Data

Continuous data are best represented by numbers, and are logically consistent when you do so. Smaller numbers = less of some measurement.

On the other hand, categorical data can be text or numeric. The value of any numbers used do not necessarily reflect any mathematical value, but it may. For example, while the values below have a natural order (The 3 Little Piggies Construction Scale), the numbers are ordinal but arbitrary:

  • 1 = reinforced concrete or steel beam
  • 2 = wood stick construction
  • 3 = baked brick masonry
  • 4 = adobe
  • 5 = sun brick / mud daub
  • 6 = straw bail

Multi-band Rasters

So far we have worked with single-channel, or 1-band rasters. However, perhaps we are more familiar with 3-channel images, because our eyes see best in the red-green-blue color space. For geospatial data, think of this as satellite or aerial views.

For digital images, 3 ‘bands’ of wavelengths are stored separately. When the computer combines them together, we humans see something akin to what we see when we look at nature with our eyes. However, we can swap in other bandwidths of radiation, such as near infrared, or microwave, and see completely other things.

The DREAM Lab hosts several satellite views of campus created by Planet Labs, a private satellite firm. Its fleet of PlanetScope satellites captures imagery in 8 bandwidth divisions of the electromagnetic spectrum. 8-band images. Let’s add one of those layers now.

Its initial appearance is dark! Let us work on its visualization. Here are some good settings to use:

Showing bands 6, 4, and 2 as Red, Green, and Blue respectively will give a good approximation of human vision. Gamma is a degree of adjustment which changes the mathematics of the values of pixels into ranges that match the combination of computer monitors and the human eye. Adjust this so that it appears most natural on your screen.

TipChallenge: play with different band combinations. What do you think Band 1 might be good for? You may want to search the web for “PlanetScope bands”

Band 1 in PlanetScope is known as ‘coastal blue’ and helps to emphasize open deep water versus shallow water with vegetation inside of it. Excellent for our kelp forests.

Layer Management and Rasters

  1. Re-order layers: Ensure vector layers (roads and paths) remain on top of the raster elevation layers in the layer stack so they are not hidden.
  2. Imagery Layers vs Basemaps:
    • A basemap sits at the bottom of the map canvas, serving purely as a static background context. Esri has options that are satellite and aerial views. You cannot perform analysis on basemaps.
    • An imagery layer is a data layer added to your map stack. It can be re-ordered above or below other layers, adjusted with transparency and blend modes, queried for pixel values, and analyze for ground cover characteristics.

NoteCRS

A note on Coordinate Reference Systems

In ArcGIS Online, the default projection and Coordinate Reference System (CRS) is WGS 1984 Web Mercator Auxiliary Sphere (also referred as EPSG:3857)

Coordinate systems can be divided into two main categories: Projected and Geographic Coordinate Systems.

  • Projected Coordinate Systems use a 2D flat surface to define locations and is measured in linear units. Locations are identified by x,y coordinates

  • Geographic Coordinate Systems use a 3D spherical surface measured in angular units to define locations on earth. A point is referred by its latitude and longitude.

There are plethora of CRSs that all have different accuracy and other advantages depending on your location and extent of your area of interest. Here is a good website to look at the different CRSs: https://epsg.io/

Editing Vector Data

Now that we have imported data into ArcGIS Online, we might also want to modify this data. For vector data, we can modify the AGO Feature Layer attributes and values stored in the underlying table or the feature itself by editing locations and shapes, or adding and removing specific features. For raster data, those transformations are generally done using some form of calculation on the entire raster, or specific values targeted via conditions, rather than by manually editing pixel values. We will talk more about raster calculations in our third workshop. For today, we will focus on editing vector data (or feature layers in ArcGIS jargon) in this workshop.

WarningThis goes beyond the map

It is important to understand that when we are editing a feature layer, it is independent of the map. You are actually changing the data stored under your content.

This also means that you might not have the right to edit some of the data you are using in your map because you do not own them! A potential workaround is to create a local copy of the data, but some data provider do not allow this either.

Analysis Workflow Overview

  1. Slope Calculation: Use raster analysis tools to calculate a slope raster from the DEM, expressing terrain steepness in degrees or percent rise.
  2. Zonal Statistics as Table: With the slope raster and the road network loaded, run Raster Analysis > Zonal Statistics as Table to compute summary statistics (such as the maximum or mean slope) for each road line.

  1. Joining Statistics to Roads: The zonal statistics tool outputs a standalone data table. To visualize these slope measurements on the map, join the table back to the road vector layer using Analysis > Tools > Summarize data > Join Features , matching on a common identifier such as OBJECTID (which is often hidden by default).

  1. Once joined, roads can be symbolized by slope steepness, allowing us to pinpoint the steepest hill climbs for our ride!
